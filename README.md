# 格物 / Inkwork

面向《工程制图》教学的线稿风格 3D 装配体图版。

运行：`npm install && npm run dev`；构建：`npm run build`；单元测试：`npm test`。计划与进度见 `docs/PLAN.md`。

字体是本地子集（`public/fonts`），新增中文文字后运行 `python scripts/subset-fonts.py <源字体目录>` 重新生成。

## 机器

- **挪动与大小**（所有机器）：打开“挪动”后按住零件拖动；选中零件后在说明卡里调“大小”（以零件自身中心缩放）；“复位”清除所有挪动和缩放。
- **逐步拆解**：拆解滑块下的 ‹ › 每次拆下一个零件（或一组螺钉），并写出这一步拆的是什么。
- **隐藏 / 只看它**：选中零件后可隐藏它，或只显示它一个；明细表里灰掉的行点一下就显示回来。
- **搜索与对准**：标题下的搜索框可以查所有机器、所有层级的零件，回车直接跳过去并把镜头对准它；选中零件后点“对准”（或按 F）也行。快捷键：/ 搜索，← → 逐步拆解，Esc 取消选择。
- **分享链接**：地址栏会跟着当前组件和选中的零件变化（如 `#model-t/piston/rings`），把链接发给别人就能直接打开同一个画面。
- **目录**：右上角“目录”打开全部机器的一览（分组、简介、零件总数、拆解层数）；第一次打开网站时自动显示。

新增机器：在 `src/machines/<id>/` 提供 `MachineDef`（子组件另设 `parent`，父级用 `children` 把零件映射到子组件；`unit` 让每一级按自己的比例显示）（零件表、拆解时序、讲解步骤、镜头、包围盒、模型组件），并在 `src/machines/index.ts` 注册。

## 两种模式

- **透视图版**：线稿 + 铅笔排线，可旋转、剖视、分层拆解、局部展开、导出图版 PNG 与拆装动画。
- **三视图**：第一角画法，主视 / 俯视 / 左视同比例对齐 + 正等轴测图；粗实线、细虚线（深度剥离求不可见轮廓）、细点画线与圆的十字中心线；剖视只作用于主视图（全剖主视图，45° 剖面线、相邻零件方向相反，剖视图不画虚线）；悬停零件显示长对正、高平齐、宽相等的投影连线。

## 蓝图配色

顶栏“蓝图”在纸面线稿和工程蓝图（深蓝底、浅色线条、琥珀色强调）之间切换；选择记在浏览器里，没选过时跟随系统的深色模式。界面颜色全部是 `src/styles/theme.css` 里的 token，蓝图在 `:root[data-theme="blueprint"]` 里重定义；3D 线稿的颜色是 `src/scene/ink.ts` 的 `PALETTES`，由 `setPalette` 改共享 uniform，切换不用重建材质；导出的图版和动画也跟着当前配色。

## 线稿渲染

`src/scene/ink.ts` + `InkRenderer.tsx` 接管 R3F 渲染循环：颜色通道、法线/零件 ID 通道、（三视图时）两层深度剥离，合成时从深度、法线、零件 ID 的不连续处提取轮廓线。三视图在同一画布内按视口逐个渲染。

## 自检

`npm run build && npx vite preview --port 5199` 后运行 `node scripts/check-machines.mjs`：在无头 Edge 里逐个打开所有机器与子组件，切到最后一步和三视图，汇报控制台错误。可加 `--jobs 4`（并发）、`--only watch,model-t/`（只测部分组件）、`--shots <目录>`（每台存一张拆开后的截图，用来检查取景）。

## 目录缩略图

目录卡片上的线稿图在 `public/thumbs/<id>.webp`，由 `node scripts/make-thumbs.mjs http://localhost:5188/`（先开 dev 或 preview 服务）在无头 Edge 里逐台渲染、按线稿裁切生成。改了某台机器的模型或镜头后，用 `--only <id>` 重新生成它。

## 用 AI 新建机器

仓库带了一个 Claude Code 技能 `.claude/skills/new-machine/`：在这个项目里对 Claude 说“加一台 X”，它会按 `SKILL.md` 的流程（定题与坐标 → 零件表与拆解时序 → 用 kit 建模 → 联动与单元测试 → 子组件分级 → 注册 → 自检截图逐张检查 → 缩略图 → 提交）做出一台新机器；`template.tsx` 是可直接复制的最小骨架。

## 展示视频

`scripts/video/` 里的三个脚本做出三分钟展示视频（1080p30，按讲稿的起承转合配十四行诗字幕）：先 `npm run build && npx vite preview --port 5199`，再依次运行 `node scripts/video/record.mjs <输出目录>/rec`（用显卡逐场景录制真实画面）、`node scripts/video/cards.mjs <输出目录>/cards`（渲染片头、片尾和字幕）、`python scripts/video/compose.py <输出目录>`（ffmpeg 剪辑合成）。录制需要 Edge 和显卡，合成需要 ffmpeg。`scripts/video/promo/` 是同样用法的 99 秒宣传片版本：隐藏界面、只留画面，七个亮点各配一张章节字幕；`music.py` 用 numpy 合成原创配乐（D 大调钢琴琶音 + 铺底 + 章节铃声）。
