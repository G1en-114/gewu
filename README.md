# 格物 / Mechanism Studio

可 3D 旋转的线稿风格机械图版：一台卧式单缸蒸汽机（气缸、十字头、连杆、曲轴、飞轮、离心调速器等 12 个零件）。

运行：`pnpm install && pnpm dev`（或 `npm run dev`），构建：`npm run build`。

## 线稿渲染

`src/scene/ink.ts` + `InkRenderer.tsx` 接管 R3F 渲染循环：

1. 颜色通道：纸色底 + 柔和明暗；剖切露出的内表面为铁锈色，选中零件叠一层锈色淡彩。
2. 法线/零件 ID 通道 + 深度纹理。
3. 合成：从深度、法线、零件 ID 的不连续处提取轮廓线、折痕线和零件分界线，以墨色画在透明背景上（CSS 纸张与淡色工程图在其下方）。
4. 叠加层（layer 1）：中心线、拆解虚线导引、飞轮旋转箭头。

## 交互

- 拖动旋转、滚轮缩放；透视 / 立面 / 平面视图。
- 分步观察：整机、剖视、传动、调速、拆解。
- 拆解滑杆、转速、剖视、标注开关；点选零件或明细表查看说明。
- 导出 PNG（当前画面）与 JSON（几何参数与零件表）。
