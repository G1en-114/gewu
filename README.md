# 格物 / Mechanism Studio

面向《工程制图》教学的线稿风格 3D 装配体图版。

运行：`npm install && npm run dev`；构建：`npm run build`。计划与进度见 `docs/PLAN.md`。

字体是本地子集（`public/fonts`），新增中文文字后运行 `python scripts/subset-fonts.py <源字体目录>` 重新生成。

## 机器

- **螺旋千斤顶**（`src/machines/jack`）：7 个回转体零件，方牙螺纹，螺旋升降；全剖时实心杆件按不剖处理。
- **机用虎钳**（`src/machines/vise`）：8 种零件，螺杆转动、方块螺母带活动钳身移动。
- **球阀**（`src/machines/valve`）：9 种零件，扳手转 90° 带动阀芯开关；全剖可见流道、密封圈与填料。
- **齿轮油泵**（`src/machines/pump`）：8 种零件，一对齿轮轴啮合，填料与压紧螺母密封。
- **弹子锁**（`src/machines/lock`）：五弹子锁芯，9 种零件（锁壳、锁芯、钥匙、上下弹子、弹簧、封片、拨片、卡簧）。动画：插钥匙时弹子随齿形起伏，插到底锁芯转 90° 再回位拔出；可切换“错误钥匙”，弹子横跨剪切线，锁芯转不动。剖视即经典的剪切线剖面。
- **四冲程汽油机**（`src/machines/ice`）：15 种零件，依 Joe Webster 的公开图纸（Webster Engine Works 4 Cycle Gas Engine，非营利用途可自由使用）按原尺寸（英寸）建模；曲柄连杆、2:1 正时齿轮、凸轮摇臂顶开排气门、自动进气门；左栏显示进气 / 压缩 / 做功 / 排气。
- **卧式单缸蒸汽机**（`src/machines/engine`）：13 个零件，曲柄连杆、配汽机构、离心调速反馈。
- **智能手机**（`src/machines/iphone`）：iPhone 15，21 种零件按 Apple 维修手册爆炸图编号，附各组螺钉；外形依 Apple 公开的配件尺寸图，内部布局按维修手册的内部视图、爆炸图和螺钉图估读（毫米）。拆解顺序照维修手册：卡托 → 后盖 → 护盖 → 摄像头 → 电池 → … → 屏幕。不含 Apple 标志。
- **土星五号**（`src/machines/saturn-v`）：阿波罗登月火箭，像展馆里那样横放，按 NASA 公布的各级尺寸建模（米）。整箭 11 个大件（三级火箭、两段间段、仪器舱、适配器、登月舱、服务舱、指令舱、逃逸塔）→ S-IC 第一级 10 件（贮箱、推力结构、液氧输送管、尾翼……）→ F-1 发动机 8 件（推力室、喷注器、涡轮泵……）。登月舱（10 件，站立着、腿展开）、服务舱（9 件：发动机、六扇区贮箱、燃料电池……）、指令舱（8 件：防热罩、承压舱、座椅、降落伞……）也都能拆开。剖视可看各级贮箱。
- **涡扇发动机**（`src/machines/turbofan`）：窄体客机级（风扇约 1.55 m）的双转子大涵道比涡扇（通用比例），13 种零件：进气道、风扇、分流环与导叶、增压级、9 级高压压气机、环形燃烧室、高压涡轮、4 级低压涡轮、低压轴、核心机匣、尾喷管、反推、附件齿轮箱。低压、高压两根转子以不同转速转动；沿轴线剖开即教科书式流道剖面。
- **手动变速箱**（`src/machines/gearbox`）：三轴式五前进档 + 倒档，15 种零件（壳体、顶盖、变速杆、拨叉、输入轴、中间轴齿轮组、输出轴、各档齿轮、倒档惰轮、三个同步器）。左栏挂档：拨叉推动接合套、变速杆在 H 形档位里移动，各轴按齿数比转动，显示速比（1 档 3.59 … 5 档 0.80，倒档反转）。
- **机械表机芯**（`src/machines/watch`）：36 mm 小秒针瑞士杠杆擒纵机芯（通用结构），17 种零件：发条条盒、中心轮、三轮、秒轮、擒纵轮、擒纵叉、摆轮、游丝、各夹板、上弦机构、表盘指针。会走：摆轮摆动 → 擒纵叉左右拨 → 擒纵轮一跳半齿 → 轮系按齿数比带动指针。剖视到夹板底面可看轮系。
- **自行车**（`src/machines/bicycle`）：公路车，13 个大件（车架、前叉、前后轮、牙盘、脚踏、链条、飞轮、前后拨、刹车、车把、座垫）。会骑：链条一节节沿牙盘—导轮—飞轮跑，车轮按 50/15 齿比转。后轮可拆开到**后花鼓**（6 件）：切换“蹬踏 / 滑行”看棘爪卡住或被棘轮齿压下。
- **T 型车**（`src/machines/model-t`）：福特 Model T 旅行车（1917–25），**逐级拆解**：整车 16 个大件 → 动力总成（17 件）/ 前桥 / 后桥 / 车轮 → 活塞连杆组、行星变速器、差速器，最深三级。依公开规格（轴距 100、轮距 56、缸径 3¾ × 行程 4、30 英寸车轮）按英寸建模；福特原厂图纸由 The Henry Ford 档案馆数字化收藏。
  - **全部展开**：整车拆开后，把动力总成、前后桥、车轮拉到车旁边排开，再各自拆开（里面的活塞连杆组、变速器、差速器也跟着拆）。
- **挪动与大小**（所有机器）：打开“挪动”后按住零件拖动；选中零件后在说明卡里调“大小”（以零件自身中心缩放）；“复位”清除所有挪动和缩放。
- **逐步拆解**：拆解滑块下的 ‹ › 每次拆下一个零件（或一组螺钉），并写出这一步拆的是什么。
- **隐藏 / 只看它**：选中零件后可隐藏它，或只显示它一个；明细表里灰掉的行点一下就显示回来。
- **搜索与对准**：标题下的搜索框可以查所有机器、所有层级的零件，回车直接跳过去并把镜头对准它；选中零件后点“对准”（或按 F）也行。快捷键：/ 搜索，← → 逐步拆解，Esc 取消选择。
- **分享链接**：地址栏会跟着当前组件和选中的零件变化（如 `#model-t/piston/rings`），把链接发给别人就能直接打开同一个画面。

新增机器：在 `src/machines/<id>/` 提供 `MachineDef`（子组件另设 `parent`，父级用 `children` 把零件映射到子组件；`unit` 让每一级按自己的比例显示）（零件表、拆解时序、讲解步骤、镜头、包围盒、模型组件），并在 `src/machines/index.ts` 注册。

## 两种模式

- **透视图版**：线稿 + 铅笔排线，可旋转、剖视、分层拆解、局部展开、导出图版 PNG 与拆装动画。
- **三视图**：第一角画法，主视 / 俯视 / 左视同比例对齐 + 正等轴测图；粗实线、细虚线（深度剥离求不可见轮廓）、细点画线与圆的十字中心线；剖视只作用于主视图（全剖主视图，45° 剖面线、相邻零件方向相反，剖视图不画虚线）；悬停零件显示长对正、高平齐、宽相等的投影连线。

## 线稿渲染

`src/scene/ink.ts` + `InkRenderer.tsx` 接管 R3F 渲染循环：颜色通道、法线/零件 ID 通道、（三视图时）两层深度剥离，合成时从深度、法线、零件 ID 的不连续处提取轮廓线。三视图在同一画布内按视口逐个渲染。
