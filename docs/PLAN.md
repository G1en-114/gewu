# 格物 · 开发计划

基线：`e64b3bc` 线稿渲染 + 卧式蒸汽机图版。

## 阶段一 · 让机器真正“工作”（已完成）

目标：每个零件的运动都有来由，讲解里的因果关系能在画面上看到。

1. **配汽机构**（新零件 13 · 配汽机构）
   - 曲轴偏心轮 → 偏心杆 → 摇杆轴（床身旁支架）→ 阀杆 → 气阀箱内的滑阀。
   - 偏心轮超前曲柄约 90°，剖视时可见滑阀往复、轮流打开两端汽口。
2. **调速反馈回路**
   - 调速器改成飞球在上、套筒在下的经典比例；套筒 → 杠杆 → 拉杆 → 节流阀摇臂。
   - 用简单的动力学代替“直接设定转速”：转速由蒸汽驱动（受节流阀开度控制）与负载共同决定，飞球张角跟随转速、再反过来改变节流阀开度。
   - 控件：「负载」滑杆 + 「调速器」开关 + 实时读数（转速 · 节流阀开度）。关闭调速器、减小负载，转速会失控上升——这是“调速”一步的演示重点。
3. 截图验收：整机 / 剖视 / 调速特写 / 拆解，各一张。

已完成：`cb4fb7d`。

## 阶段 1.5 · 爆炸图（已完成）

1. **分层拆解**：每个零件（和每组螺栓）有自己的拆解时间窗，按装配逆序依次散开——先卸螺栓、再拆缸盖、再抽活塞……拖动滑杆就像看拆装过程。
2. **螺栓独立飞出**：缸盖、阀箱盖、轴承盖的螺栓沿各自轴线飞出，并画出各自的虚线导引。
3. **局部展开**：选中一个零件后可只拆它与相邻零件，其余保持装配状态，用于讲局部。
4. **出版风格导出**：高分辨率 PNG，包含纸面、线稿、编号气泡与引线、零件明细表、标题栏。
5. **拆装动画导出**：录制“整机 → 拆开 → 合拢”的视频（WebM，带纸面背景）。

后续可选：气泡避让再优化（让气泡完全落在线稿外）；视频转 MP4 / GIF 需要服务端或 ffmpeg.wasm。
